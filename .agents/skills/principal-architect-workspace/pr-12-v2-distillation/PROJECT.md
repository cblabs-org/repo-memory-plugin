## Objective

Implement the `v2.2` Stage 1 Distillation pipeline per `SPEC.md` v1.0 (§4.6, §5.5, §6.1–§6.4, §7.1), `docs/design-v2-distillation-retrieval.md` Rev 4 (§5.1–§5.6), and `docs/addendum-a-provenance-and-hardening.md` Rev 3 (§5 A4, §8 A8):
1. **Per-Conversation Marks, Inbox Notes & Subagent Registry (`WO1`):** Track step/byte-offset/timestamp marks (`<data-dir>/<repo-id>/state/marks/<conv-id>.json`, clamping on rewind), store structured inbox notes (`<data-dir>/<repo-id>/evidence/notes/<ulid>.json` across `turn-note | mcp-note | checkpoint | artifact | sidecar` with `ExposureList` and anchor checks), record `invoke_subagent` child conversation IDs in `<data-dir>/<repo-id>/state/subagents.sqlite` from `PostToolUse`, update `memory_note` (`HandleMemoryNote`) to write an `mcp-note` inbox note and advance the conversation's mark (deduplicating against the `Stop` gate), and add `memory_status` (alias `memory_stats`) to the MCP server.
2. **Automatic Milestone-Gated `Stop` (`NO_TOOL_CALL`) Warm-Cache Continuation & Harvest (`WO2`):** On `Stop` (`executionNum == 0`), deterministically evaluate the milestone gate (`NO_TOOL_CALL`, `fullyIdle`, not subagent/housekeeping, `turn_notes: on`, milestone since mark, 30m cooldown waived for commits/PRs, ≤ 20 daily cap) and return `{"decision": "continue", "reason": "<turn-note-request>"}`. On `Stop` (`executionNum >= 1`), parse and lint the `repo-memory-note` YAML block (or `NONE`), check anchors against the working tree, attach `ExposureList`, scrub secrets, write the `source: "turn-note"` inbox note, advance the mark, and return `{}`.
3. **Free Zero-Token `CHECKPOINT` & `brain/` Artifact Harvest (`WO3`):** Deterministically extract candidate inbox notes (`source: "checkpoint"` and `source: "artifact"`) from captured `CHECKPOINT` steps (`Model Knowledge`, `User Knowledge`, `Work Accomplished`) and captured `brain/<id>/*.md` artifacts during `tick` at zero LLM token cost, deduplicated by conversation ID + step index / content hash.
4. **Preparation Layer & Layered Scrubber (`WO4`):** Implement `internal/core/pipeline/prepare/` (`SPEC.md` §6.4 / `design-v2` §5.6) and upgrade `internal/core/scrub/` (Addendum A §5: preserving valid git commit SHAs and conversation/entry UUIDs/ULIDs while scrubbing secrets and quarantining on failure): strip file reads of skills/rules/docs into 1-line stubs, drop `[repo-memory ...]` injections and `Stop` continuation prompts, reframe `CHECKPOINT` headers, wrap steps as `{i, actor, kind, text}` JSON records inside random-delimiter containers (`<session-log-<token>>`), and validate distiller outputs (step citations, echoed random token, rejection of copied instructions and tool-call syntax).
5. **Sidecar Fallback & `repo-memory-distiller` Packaging (`WO5`):** Implement Stage 1c Sidecar Fallback (`SPEC.md` §6.3.3 / `design-v2` §5.4) in `internal/core/tick/fallback.go` and package `.agents/agents/repo-memory-distiller.md` (`packaging/antigravity/agents/repo-memory-distiller/agent.md` + `cmd_install.go`): for conversations idle ≥ 2 hours (or subagents / `fallback-only` sessions) with uncovered milestone work past the mark, check quota headroom (`>= 25%` via `telemetry.CheckQuota`), prepare the input (`CHECKPOINT` + transcript tail + artifacts) via `internal/core/pipeline/prepare`, invoke `Housekeeper` (`StageDistill` / `repo-memory-distiller`), validate output, write `source: "sidecar"` inbox notes, and advance the mark.
6. **Addendum A8 Managed Instruction Block (`v2`) & End-to-End Verification (`WO6`):** Implement `internal/core/config/managed_block.go` (`<!-- repo-memory:begin v2 — managed by repo-memory; edits inside are overwritten --> ... <!-- repo-memory:end -->` with `@[memory atlas](.memory/ATLAS.md)`) and wire into `repo-memory enroll` (`init`), `repo-memory unenroll` (`leave`), and `repo-memory doctor` (checking for duplicate/unbalanced markers); rebuild `~/.local/bin/repo-memory` and verify all tests (`go test -race ./cmd/... ./internal/...`).

## Exit Criteria

- Per-conversation marks (`<data-dir>/<repo-id>/state/marks/<conv-id>.json`), inbox notes (`<data-dir>/<repo-id>/evidence/notes/<ulid>.json`), and subagent registry (`<data-dir>/<repo-id>/state/subagents.sqlite`) work deterministically and clamp on transcript rewind.
- `Stop` (`executionNum == 0`) returns `{"decision": "continue", "reason": "<request>"}` only when all milestone gate conditions pass (including `NO_TOOL_CALL`, `fullyIdle`, not a subagent, not housekeeping, cooldown/cap, and milestone since mark), and `Stop` (`executionNum >= 1`) harvests `repo-memory-note` blocks into the inbox with anchor checks and `ExposureList`.
- `memory_note` writes a `source: "mcp-note"` inbox note and advances the mark so `Stop` deduplicates; `memory_status` (`memory_stats`) returns index/inbox/dossier counts.
- Free `CHECKPOINT` and `brain/` artifact harvesting runs deterministically in `tick` at zero LLM token cost.
- `internal/core/pipeline/prepare/` and `internal/core/scrub/` enforce all §5.6 / Addendum A §5 defences and pass instruction-heavy test cases.
- Sidecar fallback (`internal/core/tick/fallback.go`) processes idle uncovered milestone sessions through `repo-memory-distiller` when quota headroom ≥ 25%.
- `repo-memory enroll` (`init`), `unenroll` (`leave`), and `doctor` manage and validate the `v2` instruction block in `GEMINI.md`.
